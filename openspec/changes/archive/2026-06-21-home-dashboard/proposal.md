# Proposal: home-dashboard

> v0.2 首个 task：把现有简陋首页改造成参考截图中的「产品工作台」仪表盘，建立全局左侧导航，为后续脚本/视频/音频/数据分析环节预留入口。

---

## 是什么（What）

将 `/` 首页从「两个卡片导航」升级为仪表盘工作台：

- 左侧固定导航栏：产品工作台、选题雷达、文案工坊，脚本/视频/音频/数据分析置灰「即将开放」
- 顶部问候语 + 当前日期 + 副标题
- 今日创作计划：3 步骤进度（浏览机会 → 确认选题 → 完成文案）
- 今日机会：pending 选题表格，带趋势分/受众匹配/新鲜度/信号来源等模拟指标
- 右侧 widgets：进行中的内容、本周产出统计、最近文案

## 为什么（Why）

v0.1 已能完成选题 → 文案的完整流程，但首页只是两个入口卡片，无法直观反映创作状态和待办事项。仪表盘能提升创作者每天打开工作台时的方向感，并自然引导后续 v0.2+ 环节（脚本、视频等）的入口。

## 范围（Scope）

### 包含
- 后端 `GET /api/v1/dashboard/stats` 聚合接口
- pending 选题的确定性 mock 指标（趋势分、受众匹配、新鲜度、信号来源）
- 全局左侧导航布局 `SidebarLayout`
- 重写 `frontend/app/page.tsx` 为仪表盘
- 适配现有 `/topics`、`/history`、`/topics/[id]` 页面宽度
- 后端测试 `dashboard.test.ts`

### 不包含
- 脚本 / 视频 / 音频 / 数据分析功能实现（仅占位）
- 真实趋势/受众算法（本次用确定性 mock）
- YouTube API 数据抓取

## 成功标准
- [ ] `/` 显示新仪表盘布局
- [ ] 侧边栏可跳转到 `/topics` 和 `/history`
- [ ] 今日机会表格显示 pending 选题 + 模拟指标
- [ ] 右侧 widgets 显示进行中内容、本周产出、最近文案
- [ ] 禁用模块显示「即将开放」
- [ ] `npm test` 通过，`npm run lint` 通过
