# Proposal: topic-library

> v0.1 追加 task：已采纳的选题进入选题库，支持 AI 自动分类并按类型浏览/筛选。

---

## 是什么（What）

把现有的「历史记录」页升级为「选题库」：

- 状态变为 `adopted` 的选题自动进入选题库
- 进入选题库时由 AI 自动打上「选题类型」标签
- 支持在历史记录页按类型筛选、按类型分组浏览
- 支持手动修正单个选题的分类
- 对历史旧数据提供「自动补分类」入口

## 为什么（Why）

v0.1 已能产出并采纳选题，但随着选题增多，创作者需要按类型（教程、评测、观点等）回顾和规划内容矩阵。自动分类减少手动打标负担，手动修正保证准确性。

## 范围（Scope）

### 包含
- 数据层：`topics` 表新增 `category` 字段
- AI 分类：选题被采纳时自动分类
- 手动修正：`PATCH /api/v1/topics/:id/category`
- 历史页升级：按类型筛选 + 分组展示 + 修改分类
- 旧数据补分类：未分类选题可一键 AI 补分类
- 单元测试与 lint

### 不包含
- 自定义新增/删除分类（仅使用预设分类）
- 分类数据分析/统计（留 v0.2）
- 影响 /topics 工作台的生成流程

## 成功标准
- [ ] 选题被采纳后自动获得 category
- [ ] 历史页按类型分组展示
- [ ] 可按类型筛选
- [ ] 可手动修改分类
- [ ] 可对未分类旧数据批量补分类
- [ ] `npm test` 通过，`npm run lint` 通过
